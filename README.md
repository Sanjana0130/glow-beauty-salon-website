# Glow Beauty Salon Website

A modern and responsive beauty salon website created as a portfolio project.

## 🌸 Features

- 💇 Hair, Hair Spa, Facial and Makeup services
- 💰 Service price list
- 📅 Appointment booking form
- 💬 WhatsApp appointment confirmation
- ⭐ Customer rating system
- 📊 Average customer rating
- 📍 Google Maps location
- 🎁 Special offers section
- 🌙 Dark / Light mode
- 📱 Mobile-friendly design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

## 🚀 Live Demo

[View Live Website](https://sanjana0130.github.io/glow-beauty-salon-website/)

## 📌 Project Purpose

This project was created to practice web development and demonstrate how a small business website can provide services, appointment booking and customer interaction.
